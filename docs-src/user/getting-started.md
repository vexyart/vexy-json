# Getting started

Vexy JSON is a drop-in parser when the input looks like JSON but was written by
a person, generated by a model, or edited as configuration.

## Python

Install the distribution with uv or pip:

```bash
uv add vexy-json
# or: python -m pip install vexy-json
```

The distribution uses a hyphen; the import module uses an underscore:

```python
import vexy_json

document = vexy_json.parse("""
{
  // Comments and trailing commas are accepted.
  project: 'atlas',
  workers: 4,
}
""")

assert document == {"project": "atlas", "workers": 4}
```

Read from a file-like object with `load`, or serialize JSON-compatible Python
values with `dumps` and `dump`:

```python
from pathlib import Path
import vexy_json

with Path("settings.json").open() as source:
    settings = vexy_json.load(source)

print(vexy_json.dumps(settings, indent=2))
```

## Rust

```bash
cargo add vexy-json
```

```rust
use vexy_json::{parse, Result};

fn main() -> Result<()> {
    let value = parse("name: 'atlas', workers: 4")?;
    println!("{value}");
    Ok(())
}
```

`parse` returns `vexy_json::Value`. Inspect values with `is_*` and `as_*`
helpers or enable the default Serde integration to move through Serde-based
code.

## Control accepted syntax

Defaults enable forgiving syntax and bounded repair. Start from defaults and
disable features explicitly:

```rust
use vexy_json::{parse_with_options, ParserOptions};

fn main() -> vexy_json::Result<()> {
    let options = ParserOptions {
        allow_comments: false,
        allow_trailing_commas: false,
        allow_unquoted_keys: false,
        allow_single_quotes: false,
        implicit_top_level: false,
        newline_as_comma: false,
        enable_repair: false,
        ..ParserOptions::default()
    };

    let value = parse_with_options(r#"{"strict": true}"#, options)?;
    println!("{value}");
    Ok(())
}
```

Python exposes the same principal switches as keyword arguments:

```python
value = vexy_json.parse_with_options(
    '{"strict": true}',
    allow_comments=False,
    allow_trailing_commas=False,
    allow_unquoted_keys=False,
    allow_single_quotes=False,
    implicit_top_level=False,
    newline_as_comma=False,
    enable_repair=False,
)
```

## Handle failures

Rust returns `Result<Value, Error>`. Python raises `ValueError` for parse
failures and exposes `is_valid()` for a boolean check. Do not use forgiving
parsing as schema validation: validate required keys, types, and business rules
after parsing.
